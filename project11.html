Project 10: Prepping for Haunted House

Task Option 3: Pulley and Drops

This task explores using a SPIKE motor to wind up and release string. String can slip off a guardrail and wrap around the motor or axle, so pulleys can guide it. With a pulley at the top, the robot can stay low while the string travels up and over to move an object up and down.

Winding Up and Letting Go

In a pulley setup, lowering an object by unwinding the string can be slow because it depends on the motor's speed. An alternative is to lift the robot, use a door or flap to hold an object such as a spider or bat, and let the motor unwind to open the flap. The object can then drop quickly, while the motor winds the mechanism back up more slowly.
